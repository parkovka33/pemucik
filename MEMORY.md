The automated suite now includes a dedicated regression test for this category-move case, and `npm run lint`, `npm run build`, and `node --import tsx --test tests/*.test.ts` all pass again.
- [2026-05-06] `/voice text` is now implemented as a narrow, safe post-MVP slice instead of a broad VoiceMaster-style toggle system. Owner changes via claim/transfer now resync the linked text channel, voice-room renames also rename the linked text channel, and stale text-channel metadata is recreated on demand if the text channel was deleted manually. `npm run db:migrate`, `npm run lint`, `npm run build`, `node --import tsx --test tests/*.test.ts`, and `npm run commands:register` all succeeded after this milestone.
